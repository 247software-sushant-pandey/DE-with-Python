# DE with Python 

A hands-on repository for Data Engineering workflows using Python. This project focuses on building scalable and modular **ETL/ELT pipelines** to extract, transform, and load data across various sources and destinations.

## Features
- ETL and ELT pipeline examples
- Data extraction from Mongo databases
- Data transformation using Python libraries
- Loading into relational and non-relational targets (initially S3). 

## Tech Stack
- Python 3.x
- Pandas, Dask etc.

## Notes
This repo is a work in progress.
